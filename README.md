# 📊 Sales Performance Dashboard

## Overview

This project presents an interactive Sales Performance Dashboard developed using Power BI and the Sample Superstore dataset. The dashboard helps analyze sales, profit, customer segments, and product performance through interactive visualizations.

## Objective

To create a business dashboard that provides insights into sales performance and supports data-driven decision-making.

## Tools Used

- Power BI
- DAX
- Sample Superstore Dataset

## KPIs

- Total Sales
- Total Profit
- Total Orders
- Profit Margin %


## Dashboard Features

- Monthly Sales Trend Analysis
- Sales by Category
- Profit by Region
- Segment-wise Sales Distribution

## Key Insights

- Technology category contributes the highest sales.
- Consumer segment generates the largest revenue.
- Sales show clear trends over time.
- Certain regions are more profitable than others.

## Outcome

Built an interactive dashboard that enables users to monitor business performance, identify trends, and make informed decisions using data visualization and time-series analysis.
